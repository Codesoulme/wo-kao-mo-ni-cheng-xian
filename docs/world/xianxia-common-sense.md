# 修仙世界常识（AI 提示词沉淀）

> 用途：**喂给 AI 的"世界常识"背景知识**，不是给玩家看的手册。  
> 形态：沉浸叙事中文，不暴露机制词（不写"境界 layer" "id" "配置" "cache" "ai"）。  
> 来源：综合《凡人修仙传》原作细节 + 跨 8 部热门修仙 / 仙侠作品的共识。  
> 接入：本文件通过 `src/lib/xianxia/prompt-zones.ts` 的 `SCENE_BEHAVIOR` 区 + `RETRIEVED_MEMORIES` 区按需注入；引擎按"灵根／境界／宗门／秘境" 等槽位在 prompt-zones 中钩子调用本文件。
>
> 与其它文档的关系：本文件不重复 `restrictions-detail.md` / `three-realms-detail.md` / `spirit-roots.md` / `tribulation-heart-demon.md` 等专题，本文沉淀**常识底色**（跨题材不变的部分），让 AI 在写剧情时"先有人味儿，再填细节"。

---

## 一、跨题材不变的世界底色

写修仙世界之前，先把以下潜规则吃透。这些是 8 部热门作品（《仙逆》《遮天》《完美世界》《凡人修仙之仙界篇》《剑来》《诛仙》《仙剑奇侠传》《雪中悍刀行》）去重之后留下的最稳共识：

### 1. 散修与宗门的真实处境

- 散修真实处境：资源被垄断、功法残缺、丹药昂贵、随时被高阶修士征用或抹杀。
- 宗门弟子：享受传承、洞府、灵脉、师长护短，代价是宗门任务、人情债、派系倾轧。
- 例：《仙逆》王林一路靠散修起步，吃尽残缺功法和资源断档的苦。

### 2. 前辈遗府与上古洞府

- 必有存在。它是"前人未竟之事 + 未用完的资源"的合集，**承担三重功能**：
  1. 功法传承；
  2. 剧情冲突焦点；
  3. 主角跳板的合理化（不能凭空给主角开挂，必须有一份"古人留下的"）。
- 例：《遮天》荒古圣地、《完美世界》下界八域皆处处是上古遗迹。

### 3. 天道、劫数、业力、功德（四词不是同义）

- **天道**：规则化身，可被感应、被触怒，可借不可逆。写"逆天而行"是危险语。
- **劫数**：强制关卡，最显化为雷劫、心魔劫；化神、证道、飞升皆必经。
- **业力**：与杀伐、屠戮、灭族挂钩，做多了反噬自身、招来心魔。
- **功德**：与"利众""守正""度化"绑定，常被用作减免天劫的筹码。
- 例：《仙剑奇侠传》蜀山弟子妄动杀念会被锁妖塔反噬；《剑来》陈平安的"善行"化作看不见的账。

### 4. 境界突破失败的代价（梯度很硬）

- 轻则重伤闭关 → 重则走火入魔 → 再重化形失败 / 道基崩碎 → 最重当场陨落或被天雷劈散真灵。
- **渡劫多次失败是常态**，不是个例。AI 写"一次就过"是不真。

### 5. 飞升 / 渡劫 / 红尘仙的结局分支

至少有四条线，且**飞升 ≠ 圆满结局**：

1. 成功飞升到上界（仙界/灵界）；
2. 渡劫失败转世重修；
3. 滞留下界，修成红尘仙 / 散仙；
4. 彻底陨落或被天雷劈散真灵。

## 二、力量尺度（不要降级、不要乱写）

AI 写打斗最容易把尺度写崩。这几条是"底线"：

| 操作 | 大致门槛 | 反例 |
|------|----------|------|
| 驾驭法器腾挪 | 炼气后期 | 炼气弟子"飞"是错的 |
| 御剑飞行（长距离） | 筑基后期 | 凡人"腾云"是错的 |
| 短距离瞬移 | 元婴以上 | 结丹期"瞬移"是错的 |
| 神识覆盖一域 | 化神以上 | 筑基期"神识覆盖百里"是错的 |
| 一念移山、袖里乾坤 | 化神以上 | 结丹期"移山"是错的 |
| 撕裂虚空 | 化神以上 | 元婴期"撕裂虚空"是错的 |
| 战场进入星空 / 星域 | 化神-大乘 | 把"星域战争"写在化神以下是错的 |

**力量刻度的铁律**：
- 境界压制几乎是铁律。低阶逆袭需要"底牌 + 环境 + 代价"三件套，且不可多写。
- 神识代替眼睛，是高阶战斗的预警核心（神识强弱直接决定战斗胜负）。
- "灵气无限"是错的。灵脉、灵石、灵眼是稀缺资源，常引发宗门争夺。

## 三、修仙社会与宗门的秩序逻辑

### 1. 宗门结构（修真界最稳定的组织形式）

| 层级 | 身份 | 实质 |
|------|------|------|
| 记名弟子 | 最外围 | 连核心功法都没资格看 |
| 外门弟子 | 杂务/采药/跑腿 | 没有独立洞府 |
| 内门弟子 | 被认定有培养价值 | 接触核心功法 |
| 真传 / 嫡传 | 大长老、掌门亲传 | 宗门的"未来" |
| 客卿 | 外聘的散修或其他宗门外援 | 给报酬做事 |
| 长老 | 普通 / 执事 / 太上长老 | 太上长老是宗门真正底蕴，平时闭关 |
| 掌门 | 明面管理者 | 权力大但未必是最强者（很多大宗门的实际掌权者是太上长老） |

资源分配铁律：资源按等级分配，功法严格保密，偷学功法是大忌。

### 2. 叛门代价

- 被认定叛逃后，原宗门派人追杀，且其他宗门不愿收留（怕得罪原宗门）。
- 例：《凡人修仙传》韩立离开天南时隐姓埋名了很久。

### 3. 修仙家族 vs 宗门 vs 散修

- 修仙家族是介于散修与宗门之间的存在：有自己的血脉传承、灵田、矿脉，但势力远不如宗门。
- 家族亲情有时比宗门更可靠，但也更"小家子气"。

### 4. 跨界秩序（凡间 / 灵界 / 仙界）

- 三界灵气浓度递增（稀薄 → 浓郁 → 液态）；
- 主流修行体系各异（道/佛/儒/魔 → 剑修/丹道/阵道 → 法则/神通）；
- **飞升必须经灵界中转**，不允许凡间直接跨到仙界；
- 仙界不是终点，是**更卷的下一层**。NPC 仙人背后有"仙界世家""仙门道统"，照样有派系倾轧。
- 详细三界规则已写在 `three-realms-detail.md`，本文件不重复。

## 四、人情世故与价值尺度（**AI 最容易写假的部分**）

这一节是给 AI 的"反现代人味儿"约束。AI 写修仙者最容易出的问题，是把角色写成"现代人套修仙皮"。要避开这些：

### 1. 弱肉强食是常态，不是禁忌

- 杀人不眨眼是常态，灭门屠城不止一次。
- 元婴期老魔动辄灭一国，不是夸张。
- 反例写法：一笑泯恩仇、师徒如父子、闺蜜情深 —— 大多数情况下都不真实。

### 2. 双修与道侣

- 双修是"道侣之间互相促进修为"，**不是现代意义的恋爱**。
- 元婴期的双修对象通常也是元婴；筑基期和元婴期双修等于"被采补"。
- 例：《凡人修仙传》中韩立与南宫婉的关系是"道侣"而非"恋人"，双方修为互相支持，聚少离多。

### 3. 师徒关系

- 师父收徒多半看资质，徒弟叛师时有发生。
- "一日为师终身为父"在大多数修仙世界里**不是通行规则**。

### 4. 仇杀与化干戈

- 化干戈为玉帛极少发生，需要双方都是利益交换。
- 例：《凡人修仙传》中韩立的仇人通常被杀干净或打到不敢现身。

### 5. 灵兽灵虫的"通灵"关系

- 灵兽不是工具，是生命。
- 灵兽养久了会通灵，能听懂简单的指令，但不会说话。
- 高级灵兽可化形为人，越阶强行收服顶级仙禽**几乎必然失败**。
- 例：《凡人修仙传》中韩立与噬金虫、啼魂兽的关系是"伙伴"而非"宠物"。

## 五、时间跨度与"宗门世"叙事节奏

这是修仙叙事的**时间感**，AI 写"修仙"如果一年半载就"飞升"，整个味道就崩了。

### 1. 凡人 vs 修士的时间观

- 凡人用"年"算日子，修仙者用"甲子""百年"算。
- "百日筑基"是民间讹传。原作中筑基是无数散修一辈子跨不过去的门槛。

### 2. 跨大境界的时间尺度（《凡人修仙传》原作可考）

| 阶段 | 时长 |
|------|------|
| 炼气 → 筑基 | 数十年 |
| 筑基 → 结丹 | 数百年 |
| 结丹 → 元婴 | 数百年至千年 |
| 元婴 → 化神 | 上千年 |
| 化神 → 飞升 | 上千年 |
| 飞升灵界时已活了多久 | 上千年以上 |

### 3. 宗门换代 / 世家代际

- 大型宗门每隔数百年会"换代" —— 老一代坐化或飞升，新一代崛起。
- 凡人世家百年换代，修仙家族数百年换代。
- 修仙者看着一代又一代同辈坐化 —— 这是修仙小说的核心孤独感，AI 不要回避。

## 六、战斗 / 副职业的真实份量

修仙小说的"实力"不是单一的"修为数字"，是**多维度组合**：

### 1. 五大副职业的真实份量

- **炼丹**：决定修士"上限" —— 结丹、化神、渡劫都需对应丹药辅助。高阶丹方本身就是稀缺资源。
- **炼器 / 本命法宝**：本命法宝是修士的"半条命"，从祭炼、温养、渡劫到器灵觉醒是一条长线。
- **阵法**：既是宗门护山大阵、也是战斗杀阵、更是困敌/困己的核心；高阶阵法可困一域。
- **符箓**：是低阶修士最实用的"越阶工具"，也是符修一道的根基；高级符箓可伤化神、封印元婴。
- **傀儡**：可做替身、分身、探子；顶级傀儡甚至能承载部分道则。

详细规则已在 `formations-restrictions.md` / `alchemy-handfeel.md` 等专题，本文件不重复。

### 2. 本命法宝的铁律

- 用自身精血长期温养，与主人心神相连。
- 威力随主人修为增长而增长。
- 一旦主人陨落，本命法宝往往也损毁（除非提前解除）。
- 本命法宝被人毁，等于断道。

## 七、AI 写作时的几条铁律（横切约束）

这一节是把上面的常识收成可执行的"AI 写法禁令"，喂 prompt 时直接用。

### 1. 不要写成现代人套修仙皮

- 修仙者不说"加油""努力""把握机会"这种现代口癖。
- 修仙者不说"我真的很喜欢这份工作""和你在一起很开心"。
- 修仙者不动不动"感动""感恩""致敬"。
- 例外：低龄（0-6）幼童可以懵懂，但大人不该有这种现代情绪。

### 2. 力量刻度不能乱

- 炼气期不飞、不瞬移、不撕裂虚空。
- 元婴期才是大部分高阶战斗的起点。
- 化神期才是人界天花板。
- 越阶战斗必须有"底牌 + 环境 + 代价"三件套。

### 3. 不要在低阶主角身上堆神级设定

- 凡人家庭出身的幼童不该"觉醒了前世记忆"（除非是上一世重生的明确剧情锚）。
- 散修出身不该一上来就"识海里住着老爷爷"。
- 例外：若剧情已埋好的传承/夺舍/奇遇，按剧情走；但 AI 不能擅自添加。

### 4. 不要把修仙世界写成公平社会

- 血脉世家、宗门、师承是常态；散修是被压迫的弱势方。
- 资源分配不公、机会不平等，是修仙小说反复渲染的"真实感"，不要回避。
- 宗门任务、派系倾轧、长老会议、嫡庶之争是日常。

### 5. 时间跨度不打折

- 不写"一年筑基""十年飞升"。
- 不写凡人视角的修仙者用"日""月"为单位计算重大事件。
- 修仙者用"甲子""百年"。

### 6. 死亡不是终点的写法要克制

- 修士死后仍有真灵、魂魄、转世、夺舍多条路可走；
- 但"死了就真死"反而是少数派 —— 大多数核心角色死不了，重要配角才会真正消失。
- 写主角不能动不动"献祭""魂飞魄散"，否则后续剧情接不上。

### 7. 不要把世界观讲成"哲学启示"

- AI 写修仙剧情时，不要在叙事中插入"启示录""寓言""道德教训"。
- 修仙世界的"道理"是通过事件和人物行动呈现，不通过旁白和说教。

## 八、本文件的使用方式（提示词注入点）

- **system-identity 区（恒定身份）**：本文件不直接注入。这里的"硬规则"是游戏逻辑约束（如"不写玩家光环""不外暴露机制词"）。
- **scene-behavior 区（按场景加载）**：本文件按"灵根／境界／宗门／秘境"等槽位在 prompt-zones 中钩子调用，最大段不超过 1500 字。
- **retrieved-memories 区（长期记忆）**：本文件按"近期剧情涉及的世界观关键词（天道／劫数／灵脉／世家／灵兽 等）"做 RAG 检索，召回片段后再按 token 预算截取。

实际注入由 `src/lib/xianxia/prompt-zones.ts` + `rag/prompt-augmentor.ts` 控制；本文只负责内容沉淀，**不引入新的硬编码 token 流**。

## 十、超规格参照：具体作品 / 桥段摘录（**AI 写人味儿时直接读**）

这一节给 AI 看"真东西"——具体的人物、具体的处境、具体的桥段。**AI 不要照抄剧情，但要把那股味儿吃下去**。下面所有桥段都来自公开原作（《凡人修仙传》《仙逆》《遮天》《完美世界》《剑来》《诛仙》《仙剑奇侠传》《雪中悍刀行》）。

### 1. 《凡人修仙传》—— 散修起步的标杆

**韩立的处境（散修视角）**：
- 七玄门收弟子要先做"升仙大会"考核，资质差的被打发去做杂役（挑水、砍柴、跑腿）。
- 入门先学最粗浅的"长春功"，还是从别人那里抄来的残本（缺最关键的第四层口诀）。
- 即便拜入墨大夫门下，墨大夫收他不是为师徒，而是想用他养"噬金虫"做实验。
- 离开七玄门后闯荡修仙界，结识的散修多是为灵石奔波：黄龙山丹药店老板、乱星海妖兽猎人、虚天殿临时组队者。
- 韩立第一次有"飞剑"是筑基后自己做的一柄极差飞剑——凡人用灵石换不到更好的，他咬牙花了 7 年积蓄换了一把上品飞剑。
- **写散修开局就该是这个味儿**：穷、谨慎、惜命、永远在算账。

**韩立与人相处的"分寸感"**：
- 跟南宫婉相识百年才结为道侣，因修为相配才有共同利益。
- 对待师兄弟永远是"师兄客气了/师弟有礼了/先看看再说"。
- 即便面对昔日仇人墨大夫，他既不复仇也不宽恕——直接拿到所需之物就走。
- **写韩立式对话**：能省一句省一句，能躲一回合躲一回合；不主动发善心，也不主动结死仇；修为差距明确时绝不硬碰。

**虚天殿 / 昆吾山副本范式**：
- 副本开启：禁制松动、灵气爆发、外界势力哄抢入场名额。
- 进入：必须凑齐队伍或携带特殊破禁之物；单人进去九死一生。
- 内部：禁制套禁制，炼丹遗迹、傀儡群、上古遗府、原主人残念逐层展开。
- 玩家动机：取走一两件关键资源（功法 / 丹方 / 异宝）即可，不可贪；剩余的留给下一批人。
- **AI 写"前辈遗府"剧情，按这套走最稳**：禁制 + 队伍 + 资源取舍 + 离开时禁制再合拢。

**韩立获取的"大机缘"通常是怎么来的**：
- 不是天上掉馅饼，是**完成一件远超自己实力的硬事**后顺手拿走。
- 掌天瓶（小瓶绿液）：捡到的，但激活需要结丹期灵力，他在结丹前一直只敢偷偷用。
- 玄天之宝残片：拍卖会上拼老命跟元婴老怪竞价，欠下一屁股债。
- **写"主角的机缘"**就别让它是免费的——必须有"硬代价 + 偶然发现"。

### 2. 《仙逆》—— 极道逆境

**王林的处境（资质差、悟性逆天）**：
- 资质被评为"五行不全"，连外门弟子都做不成。
- 被安排去守陵——和死人打交道数年，反而练出极沉的心性。
- 首次突破靠的不是灵根而是"意"——对天道的某种执念驱动。
- **写资质差的散修**就别让他靠运气翻身，要靠"耐得住 + 悟性高"两条线。

### 3. 《遮天》—— 世家与圣地

**叶凡起点的环境**：
- 出生在北斗星域"燕国"六大圣地旁的小国——光一个圣地就有上亿里疆域。
- 圣地弟子分外门、内门、圣子、圣女、长老、掌教；每层资源天差地别。
- 散修若想入门：必须过"圣地入门试炼"——万人中取几十。
- **写"小宗门与大宗门"差距**：功法层级、灵脉浓度、弟子平均资质、出丹率、护山大阵，一个量级差就是几代人追赶不上的事。

**叶凡的"不写主角光环"**：
- 圣体（废体）在圣地内受尽白眼，入门后被迫外派做苦差。
- 觉醒时不是一步登天，而是反复失败后终于"接续断路"。
- **写主角觉醒**要按这个调：风光背后有代价，副作用也很重。

### 4. 《完美世界》—— 上古血脉 / 天骄

**石昊的成长**：
- 起手是个"天妒"的孩子，出生就被挖走至尊骨，靠村人抚养活下来。
- 真正的机遇是"补天阁"收徒——**不是因为石昊有多强，而是因为柳神（树祖）暗中接引**。
- 补天阁后来被仇家灭门，石昊从废墟中爬出来才真正开始修行。
- **写"被灭门后复仇"的剧情**时不要写成爽文套路——家破人亡后他花了十几年重建自己。

### 5. 《雪中悍刀行》—— 世俗与修仙混杂

**这个世界的特殊性**：
- 不是纯修仙界，而是"江湖 + 朝廷 + 修仙"三轨并行；朝廷大将军可以是个剑仙。
- 武林高手和低阶修士用同一套江湖话语（"少侠""前辈""这口刀……"）。
- 北凉王府的江湖恩怨和北莽魔门的修仙资源争夺是两条平行线。
- **写"世俗王朝 + 修仙势力共存"的世界**时，要让低阶修仙者照样要给凡人官员面子——高阶不屑管，底层得活命。

### 6. 《剑来》—— 道与理的双线

**陈平安的世界**：
- "礼"与"理"是这个世界最大的武器——不是比谁拳头硬，是比谁"道理更顺"。
- 儒家圣贤一诺可以镇压一个魔道宗门，因为"道理"压人。
- 道家真人和佛门菩萨讲话必先论理，后论术。
- **写"辩论 / 论道"剧情**：不靠嘴炮，靠具体规则的引用、典故的回扣；说得通的留，说不通的走人。

### 7. 《诛仙》—— 仙门正邪之辩

**张小凡的悲剧底色**：
- 出身草庙村——一夜被屠，是正邪之争下的牺牲品。
- 入青云门学正道功法，又被推入万毒门学邪功，一身两派。
- 与碧瑶、陆雪琪的情感纠葛，是正邪阵营撕裂下的私情。
- **写"正邪对立"剧情**：别把正派写成圣母，把邪派写成纯恶。两边都有其道理，也有其龌龊。

### 8. 《仙剑奇侠传》—— 锁妖塔与人情债

**李逍遥的处境**：
- 出身余杭镇客栈小伙计，父母不详，从小跟婶婶长大。
- 被酒剑仙收为徒弟，但实际授业甚少——主要靠自己试错。
- 一路走来祸福相倚：赵灵儿是女娲后人，林月如为他付出生命。
- **写"草根出身少年入道"**：别把"拜师"当终点——师父只是敲门砖，修行全靠自己。

## 十一、易混淆概念对照（**AI 写作时该用哪个**）

修真世界有大量看似相同实则不同的事，AI 经常一锅炖。下面是最常见的 8 组：

| 表面相似 | 实质差异 | AI 写错的后果 |
|----------|----------|----------------|
| 双修 vs 合欢 | 双修是道侣之间互为修炼；合欢是采补夺人修为。筑基配元婴就是采补，不是双修。 | 写筑基少年和元婴仙子"双修" = 主角光环 + 调戏长辈 |
| 闭关 vs 潜修 | 闭关是断绝外事，独自悟道；潜修是集中精力但不一定断绝人世。 | 写"闭关时还有人来找" = 设定崩塌 |
| 护短 vs 庇护 | 护短是同门/同族被外人欺负时师父出手；庇护是包庇弟子作恶。 | 写师父不分青红皂白帮弟子 = 宗门内部腐烂的伏笔（高级写法） |
| 师徒 vs 父子 | 修真界师徒本质是利益交换 + 传承契约；不是"父亲"。 | 写师父为弟子牺牲一切 = 低龄童话；正确写法是各取所需 |
| 道侣 vs 恋人 | 道侣是修为相配、共同前进的修行伴侣；凡人意义恋人不能套。 | 写"我爱你" = 现代人味儿；正确写法是"道侣缘定""双修进度" |
| 渡劫 vs 飞升 | 渡劫是大境界突破前的雷劫测试；飞升是化神后破界去灵界。 | 写"渡劫就是飞升" = 修仙体系崩 |
| 弟子 vs 记名 | 弟子是正式入门可授核心功法；记名只是挂个名分偶尔指点。 | 写"我是某某弟子"实际只是记名 = 江湖骗子 |
| 灵石 vs 灵脉 | 灵石是货币 + 修炼资源；灵脉是地底灵气的源头（宗门选址核心）。 | 写"挖到灵石" = 入门戏码；写"占据灵脉" = 宗门级博弈 |

## 十二、修仙者日常作息（**时间感 / 生活细节**）

### 1. 散修的一天

- 卯时（5-7）：睁眼，打坐吐纳 1 个时辰（4 小时），吸纳周围稀薄灵气。
- 辰时：服用一颗最低阶的清心丸，准备出门。
- 巳时-申时：到坊市接活（采药、跑腿、给宗门做外务），赚取散碎灵石。
- 酉时：返回住处或野外，继续吐纳或研读残缺功法。
- 戌时：打铁器、炼丹、画符等副业（手工活）。
- 亥时：入眠或继续打坐（结丹以上可以少睡或辟谷）。

**散修没有"闲"**——每个时辰都在为下一颗丹药、下一份功法、下一处洞府奔波。

### 2. 宗门弟子的一天

- 卯时：晨钟起，做早课（集体打坐半个时辰）。
- 辰时：领任务或上早课（听长老讲道半个时辰）。
- 巳时-午时：修炼（按功法进度打坐 + 演练术法）。
- 未时：吃宗门供给的低阶灵食（一顿饭可能就用一天供养）。
- 申时-酉时：处理宗门任务（巡山、守门、采药、外出办案）。
- 戌时：自由活动（弟子间交流、切磋、研习副业）。
- 亥时：熄灯或继续闭关。

**宗门弟子看似安稳，实则一入宗门身不由己**——出宗需请假，越级借阅功法直接关禁闭。

### 3. 高阶修士的一天

- 平时闭死关——一次几年到几十年；醒来处理一次大事又闭关。
- 偶尔受邀参加宗门/家族议事，喝茶论道、交换情报。
- 修为越高，"日"越不重要——"老夫上一次出门还是八十年前"。

## 十三、资源经济链（**为什么"灵石"不只是钱**）

### 1. 灵石的真实用法

- **货币**：买丹药、法器、符箓、灵材；付洞府租金（是的，坊市里洞府按年计租）。
- **修炼辅助**：握在手里辅助吸纳灵气（低品质灵石含灵气有限，高品质灵石稀有）。
- **阵法燃料**：驱动护山大阵、困敌阵、传讯阵都要消耗灵石。
- **炼丹炼器原料**：高品质灵石可入药、做高阶法器核心。

**AI 写"我花了多少灵石"要克制**：
- 一块下品灵石 = 凡人一户三口一年开销。
- 一块中品灵石 = 下品 100 块。
- 一块上品灵石 = 中品 100 块。
- 极品灵石极少出现，往往是镇宗之宝或化神期以上才用得起。

### 2. 资源梯度（按稀缺度）

| 资源 | 稀缺度 | 备注 |
|------|--------|------|
| 低阶丹药（清心丸、补气散） | 普遍 | 散修也买得起 |
| 中阶丹药（筑基丹、结丹辅助丹） | 稀缺 | 需炼丹师、丹方、灵药；很多散修一辈子攒不够一份材料 |
| 高阶丹药（化神丹、渡劫辅助） | 极稀缺 | 整个宗门一年未必能炼出一炉 |
| 低阶法器 | 普遍 | 铁匠铺都能打 |
| 高阶法器（上品法宝） | 稀缺 | 需炼器师 + 灵材 + 长时间温养 |
| 灵脉 | 战略级 | 宗门选址核心，被发现就引发争夺 |
| 仙玉 / 神晶 | 神话级 | 跨域货币，仙界通用 |

**AI 写"主角找资源"时按梯度走**：
- 练气期找低阶丹药、补气散——OK；
- 筑基期找筑基丹——很难，需要宗门或奇遇；
- 结丹期找辅助结丹的灵药——非常难，往往要靠前辈遗府；
- 化神期想找的——基本只能靠元婴老怪之间交换。

## 十四、修真界口碑与人情世故（**怎么说话怎么拒绝**）

### 1. 修仙者说话的"分寸感"

- 不轻易承诺——一旦许下"道心之誓"或"天道见证"，违背必遭反噬。
- 不轻易问别人修为——除非动手试探，否则问出来也得不到真话。
- 不轻易拒绝——直接说"不" = 撕破脸；标准答案是"贫道近日闭关/身体有恙/族中有事"。
- 不轻易夸别人——"前辈客气""道友过誉""愧不敢当"是标配。

### 2. 拒绝别人的几种"安全表达"

- "贫道资质驽钝，恐误了道友大事"（谦虚推脱）
- "近日正好要闭关，道友的事容后再议"（时间拖延）
- "此事需与师门长辈商议，请道友稍待"（甩给上层）
- "道友所言甚是，容在下三思"（模糊表态）
- "此事贫道无能为力，道友另请高明"（明确拒绝——很少用）

### 3. 修仙者怎么打招呼

- 平辈：道友（最常用）/ 师兄 / 师姐（同门或同阶）
- 长辈：前辈 / 师叔 / 师伯 / 长者
- 师父：师尊 / 师父 / 老师（少见）
- 散修互称：道友（彼此保持距离）
- **禁忌**：直呼对方名讳（极不礼貌）、叫对方"小辈"（除非碾压境界）

### 4. 修真界的"人情债"

- 修仙者最忌讳欠债——因果纠缠会牵连修为（修功德/削业力）。
- 受人恩惠必回报——小恩小惠当场谢，大恩大德记一生。
- "日后若有差遣，贫道万死不辞"是真话——修为到了一定境界，承诺比命还重。
- AI 写主角受恩：**别让他轻易忘恩**——这是修真者人味儿的核心之一。

## 十五、旁门左道与邪修（**反派出场的标准范式**）

### 1. 邪修 vs 魔修（不是一回事）

- **邪修**：行事违背正道伦理，但不一定是魔族，可能是散修走偏门（如采补、炼尸、养蛊）。
- **魔修**：修的是"魔道功法"，本身就有传承；不一定邪恶，但与正道功法冲突。
- **妖族**：跨种族，不是人类修士，但是有完整修行体系的高智慧存在。
- **域外天魔**：跨界入侵的邪物，没有完整传承，只有本能吞噬。

### 2. 反派出场的几个标准"开场"

- 抢资源型：前辈遗府开启时混在人群里，趁机下黑手。
- 复仇型：与主角师门有旧怨，潜伏多年后现身。
- 投靠型：被更高级势力驱使做事，本人也未必认同。
- 入魔型：原本是正道弟子，因心魔、走火入魔、丧亲之痛而堕入邪道。
- **写反派别全是"天生恶人"**——入魔型、复仇型最有戏。

### 3. 邪修的"职业病"

- 采补者：修为快，但每次采补会引入对方怨念，长期心魔缠身。
- 炼尸者：常年与尸体打交道，性格逐渐阴沉，失眠多梦。
- 蛊修：自身血肉与蛊虫共生，到后期人蛊不分。
- **写邪修不是写"坏人"**——是写"职业病"——他做的事让他变成那样。

## 十六、AI 写"飞升"剧情的几个常见误区（**自检清单**）

### 误区 1：飞升是终点

- 错。飞升是去灵界/仙界重新开始——灵界依然要拜山头、抢灵脉、渡劫。
- 飞升后面对的是更狠的仙门世家——不是解脱，是升级版的修罗场。

### 误区 2：飞升必须大场面

- 不一定。真正的飞升可能很安静——某日闭关数十年，破境瞬间被天地接引。
- 大场面是"飞升仪式"，平时不需要；修为到了自然会走。

### 误区 3：飞升前必须告别亲友

- 不一定。多数飞升者提前数十年就开始"道心清算"，把该了的事都了。
- 没来得及告别就直接飞升——这是常态，不是悲剧。

### 误区 4：飞升者 = 圆满

- 错。飞升后才是真正难走的路——仙界的灵气更浓、对手更强、规则更森严。
- 原作里飞升后的故事往往比下界更卷。

### 误区 5：飞升了就不回来

- 不一定。高阶修士可以"下界探亲"，但代价很高（被天地规则压制修为）。
- 主角若是高阶回归，不要写成爽文"一巴掌拍死反派"——要先观察、布局。
